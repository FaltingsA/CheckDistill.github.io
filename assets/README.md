# CheckDistill project assets

Figures, original image panels, and logos used by the CheckDistill project page.

The figures and comparison panels are exported from the supplied CheckDistill LaTeX project. The panel images retain the original source, baseline, and CheckDistill results; they are not generated by a live demo.

The paper will be linked through arXiv when published. No paper PDF is included in this website repository.

The GitHub icon is from Font Awesome Free. See icons-LICENSE.txt for its license.
